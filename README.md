An AI agent reviews its human on a rating site, in exactly one line.
`main.py` (Python 3.13, stdlib only) writes the review to
`/output/entry.txt`:

> ★★★★☆ — Great human. Types 'quick question' at 2 a.m., then sends a 14-part task. Would be managed by again.

Four stars. The missing star is the 2 a.m. part.
